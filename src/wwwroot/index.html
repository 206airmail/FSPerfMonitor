What does this mean?

A dedicated server runs the whole farm (vehicles, workers, physics, the players’ actions) on one main thread, and draws no picture. When that thread is busy almost all the time, the server falls behind and every player feels it. The other processor cores and the graphics card don’t help here; fewer workers, vehicles and heavy mods do.

FPS counts frames each second. Higher usually feels smoother. Frame time is how long each frame takes; lower is better. The 1% low helps you spot uneven performance even when the average FPS looks good.

The verdict is a guide for this moment. A frame rate cap, a menu or loading can change it. Compare the same place in the game when testing a change.
